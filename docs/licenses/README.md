# Bundled fonts

Both families are bundled in `app/src/main/res/font` rather than downloaded at runtime, so the
scoreboard reads the same on a phone with no signal.

- **Montserrat** (`montserrat_600/700/800.ttf`) — every number and every screen title.
  SIL Open Font License 1.1, see `Montserrat-OFL.txt`. From
  <https://github.com/JulietaUla/Montserrat> (the upstream project; Google Fonts now ships
  Montserrat only as a variable font).
- **Barlow** (`barlow_400/500/600/700.ttf`) — all other text. SIL Open Font License 1.1, see
  `Barlow-OFL.txt`. From <https://github.com/google/fonts/tree/main/ofl/barlow>.
